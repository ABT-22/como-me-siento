# ¿Cómo me siento?

App para trabajar el reconocimiento de emociones con alumnado TEA de 1.º de Primaria.

Al pulsar una emoción, la tarjeta se resalta y una voz dice la frase. Si el alumno elige triste, enfadado o miedo, aparece una estrategia de calma.
